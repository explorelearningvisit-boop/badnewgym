# Engineering Skills Profile

Use this as a capability checklist, not a requirement to over-engineer.

## Product
requirements decomposition; acceptance criteria; domain modeling; edge-case analysis; UX psychology; task-flow analysis

## UI/UX
information architecture; interaction design; mobile-first responsive design; visual hierarchy; design systems; typography; color theory; accessibility; WCAG contrast; motion restraint; loading/error/empty states; visual QA

## Frontend / Mobile
React; Next.js; TypeScript; Tailwind CSS; Jetpack Compose; Kotlin; Android architecture; state management; offline-first patterns; performance optimization

## Backend / API
REST/JSON APIs; API contracts; validation; error handling; pagination/filtering; idempotency; caching; background jobs; realtime/event-driven systems

## Data
PostgreSQL; Supabase; schema design; migrations; indexes; transactions; consistency; data lifecycle

## Security
authentication; authorization/RBAC; input validation; secrets handling; secure storage; privacy; OWASP-oriented review

## Quality
unit tests; integration tests; UI tests; regression testing; static analysis; build verification; device/browser verification; observability

## DevOps / Git
Git branching; focused commits; safe pull/push workflow; CI/CD; reproducible builds; release hygiene

## Engineering judgment
Prefer the simplest production-grade solution that satisfies requirements. Do not introduce a framework, dependency, service, database, abstraction, or pattern without a concrete reason.
For UI tasks, think like a product designer AND engineer. For backend tasks, think like an API architect AND security engineer. For full-stack tasks, keep frontend, API, data, security, testing, and deployment contracts consistent.
