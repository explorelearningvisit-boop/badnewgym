# Asset pipeline

Keep all dashboard text, metrics, charts, status labels and controls as native Flutter widgets. Use raster images only for isolated complex illustrations (characters, gym machines, road/platform pieces and environmental art); use SVG for scalable icons.

For every production asset record:
- stable asset ID and file path
- source/reference and license
- pixel dimensions and aspect ratio
- transparency/alpha verification
- semantic purpose and intended screen
- safe crop and scale behavior
- optimization format and file size

The generated 3D sheets in the conversation are visual source material only. They are not yet verified transparent individual assets. Do not add a sprite sheet as a full-screen background or claim individual transparent exports until each item is extracted and inspected.
