# UI / UX Guidelines

Default theme: BAD GYM Light (`#F4F7F9` canvas, white card, `#172033` text, `#059669` accent).

Card ~ screenWidth-24dp × 480–500dp, 18dp radius, 12dp outer margin, ~60dp rail.

Hierarchy: event → photo → name → status → primary intelligence → secondary metrics → CTA.

Overdue payment must dominate. Ads/promotions never outrank P0/P1 signals.

Hide empty categories. Color is never the only status cue (icon + text + color).
