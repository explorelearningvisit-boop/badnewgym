# BAD GYM Visual System V3

## Themes
Natural Fresh
- mint/leaf/cream/white
- soft botanical ornaments

Futuristic Neon
- deep navy
- cyan/electric green/violet
- selective neon rails and edge glow

Minimal Dark
- charcoal
- white/soft gray
- emerald accent
- low ornament density

Glassmorphism
- translucent white/blue/lilac surfaces
- soft blurred/gradient background
- high legibility fallback when blur is unavailable

Premium 3D
- champagne/gold/emerald/deep charcoal
- layered elevation/highlight
- restrained metallic feel

Vibrant Gradient
- purple/blue/pink/green
- gradient surfaces with controlled saturation

Gym Beast Mode
- charcoal/red/electric green
- performance-oriented angular ornaments

Purple Royal
- violet/purple/lavender/silver
- premium jewel-like accents

## Tiers
NORMAL, SILVER, GOLD, PREMIUM, VIP, ELITE, CORPORATE, TRIAL, WALK_IN

Tier controls:
- membership badge
- decorative border/accent
- rail selected state
- small icon treatment
- subtle surface accent

Tier never overrides:
- danger/error
- warning
- success
- disabled/locked states

## Shape language
- shell radius 24dp
- inner card radius 18dp
- metric radius 16dp
- pill radius 999dp
- rail width 66–76dp depending on available width

## Motion
- menu transition 180–250ms
- theme transition 180–250ms
- press scale 0.98 max
- no constant shimmer/pulse unless representing live state

## Accessibility
- 48dp minimum touch targets
- text + icon + color for semantic statuses
- sufficient contrast
- font scaling support
- content descriptions
