# BAD GYM Natural Fresh — Visual Acceptance Specification

The repository reference image is authoritative for the Natural Fresh Home state.

## Composition
- premium rounded outer shell
- pale mint/white glass-like surface
- integrated left rail
- large two-column hero
- large rectangular portrait with rounded corners
- strong event pill
- large time hierarchy
- Gold Plan band
- ACTIVE band
- three equal metrics
- full-width green CTA
- botanical framing at top/right/bottom
- decorative "Small Steps Big Results" footer message

## Reference hierarchy

Event > member identity > membership > active state > decision metrics > CTA.

The intelligence engine may provide signals, but the Natural Fresh reference Home state must not be drowned by multiple large alert cards.

## Visual constraints

Use semantic tokens rather than arbitrary per-component colors.

Natural Fresh:
- near-white / pale mint background
- emerald/leaf green primary
- champagne/gold membership accent
- red/pink only for payment problem
- navy/deep ink text
- subtle borders and soft shadows
- botanical PNG/vector layers with restrained opacity

Avoid:
- tiny portrait circles
- tiny event chips
- oversized empty whitespace
- generic Material-looking cards
- arbitrary icon containers everywhere
- multiple competing CTA/alert blocks
- duplicated back controls
- dark backgrounds in Natural Fresh
