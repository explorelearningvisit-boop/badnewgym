BAD GYM Graph Spec V3

Recommended native Compose chart dependency: Vico, subject to version compatibility with the existing version catalog.

Attendance: 4-8 week trend, current period visit rate, weekday heatmap only with enough data, target marker when target exists.
Payments: monthly payment trend and overdue aging.
Workouts: weekly sessions, duration trend, routine consistency.
Trainer: purchased vs used sessions and upcoming sessions.
Insight: trends derived from real signals only.

Each chart needs title, period, accessible description, empty state, insufficient-data state, and source/evidence label when useful. Graphs must answer a decision question; never add charts merely to fill space.
