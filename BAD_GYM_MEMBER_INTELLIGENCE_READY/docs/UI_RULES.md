# UI Rules

Hierarchy:
1. Event
2. Member identity
3. Membership status
4. Primary intelligence
5. Supporting signals
6. One contextual action

The Home view is not a dashboard dump.
Detail menus are evidence.

Semantic states override decorative theme colors:
- danger stays visually dangerous
- success stays positive
- warning stays cautionary

Themes may change hue, surface, glow and typography treatment, but must not change business meaning.
