14. Missing data is not zero, absent, holiday or missed payment.
15. Required loop: inspect → implement → build/test → run → screenshot → compare → fix → re-run → verify → record evidence.
16. Do not merge PR #6 or instruct the user to pull `main` for these unmerged changes before verification/review.
